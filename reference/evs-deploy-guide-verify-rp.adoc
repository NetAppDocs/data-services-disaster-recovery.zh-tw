= 驗證NetApp Disaster Recovery中一切正常
:allow-uri-read: 


[role="lead"]
在 NetApp Disaster Recovery 中新增複寫計畫後，請先驗證該計畫是否處於 *Healthy* 狀態，然後再繼續。

圖：複製計劃頁面image:evs-replication-plan-post-create.png["複製計劃頁面"]

NetApp Disaster Recovery 會執行一系列測試，以驗證所有元件（包括 ONTAP 叢集、vCenter 叢集和 VM）是否可存取並已準備好進行保護。這稱為法規遵循檢查，並且會定期執行。

複寫計畫頁面顯示以下資訊：

* 上次合規性檢查的狀態
* 複製計劃的複製狀態
* 受保護（來源）網站的名稱
* 複製計劃保護的資源組列表
* 故障轉移（目標）站點的名稱
