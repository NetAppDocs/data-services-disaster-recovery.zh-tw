= 將 NetApp Disaster Recovery 新增至您的 Amazon EVS Console 帳戶
:allow-uri-read: 


[role="lead"]
NetApp Disaster Recovery是一種授權產品，必須先購買才能使用。有多種類型的許可證，您可以透過多種方式購買許可證。許可證授權您在特定時間內保護特定數量的資料。

如需有關災難恢復授權的詳細資訊，請參閱link:../get-started/dr-licensing.html["設定災難恢復授權"]。



[[license-types]]
== 許可證類型

許可證主要有兩種類型：

* NetApp 提供 link:../get-started/dr-licensing.html["30天試用許可證"]，讓您可以使用 ONTAP 和 VMware 資源來評估災難恢復。此授權提供 30 天的使用期限，可保護無限量的容量。
* 如果您希望在 30 天試用期結束後繼續獲得 DR 保護，請購買正式版授權。您可以透過 NetApp 的任何雲端合作夥伴的市場購買此授權，但針對本指南，我們建議您使用 Amazon AWS 市場來購買災難恢復的市場授權。若要深入瞭解有關透過 Amazon 市場購買授權的詳細資訊，請參閱 link:../get-started/dr-licensing.html["透過 AWS Marketplace 訂閱"]。




[[size-your-disaster-recovery-capacity-needs]]
== 確定災難復原容量需求

在購買許可證之前，您應該了解需要保護多少ONTAP儲存容量。使用NetApp ONTAP儲存的優點之一是NetApp儲存資料的效率很高。  ONTAP磁碟區中儲存的所有資料（例如託管虛擬機器的 VMware 資料儲存區）都是以高效率的方式儲存的資料。 ONTAP在將資料寫入實體儲存時預設採用三種儲存效率：壓縮、重複資料刪除和壓縮。最終結果是儲存效率在 1.5:1 到 4:1 之間，具體取決於所儲存的資料類型。事實上， NetApp提供了 https://www.netapp.com/media/79014-ng-937-Efficiency-Guarantee-Customer-Flyer.pdf["儲存效率保證"^]對於某些工作負載。

這對您有優點，因為災難恢復在套用所有 ONTAP 儲存效率後，會計算容量以進行授權。例如，假設您在 vCenter 內配置了 100 TB (TiB) 的 NFS 資料存放區，以託管您想要使用該服務保護的 100 個 VM。此外，假設當資料寫入 ONTAP Volume 時，自動套用的儲存效率技術會導致這些 VM 僅消耗 33 TiB（3:1 儲存效率）。災難恢復只需授權 33 TiB，而非 100 TiB。與其他 DR 解決方案相比，這對您的 DR 解決方案的總擁有成本來說，可能是一個非常大的優點。

.步驟
. 若要確定託管要保護的 VMware 資料儲存庫的每個磁碟區上消耗的資料量，請透過對每個磁碟區執行ONTAP CLI 命令來確定磁碟容量消耗： `volume show-space -volume < _volume name_ > -vserver < _SVM name_ >` 。
+
例如：

+
[listing]
----
cluster1::> volume show-space
Vserver : vm-nfs-ds1
Volume  : vol0
Feature                                Used      Used%
-----------------------------      --------     ------
User Data                           163.4MB         3%
Filesystem Metadata                   172KB         0%
Inodes                               2.93MB         0%
Snapshot Reserve                    292.9MB         5%
Total Metadata                        185KB         0%
Total Used                          459.4MB         8%
Total Physical Used                 166.4MB         3%

----
. 注意每個磁碟區的“總物理使用量”值。這是NetApp Disaster Recovery需要保護的資料量，也是您將用來決定需要許可多少容量的值。
