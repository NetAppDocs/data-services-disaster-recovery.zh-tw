= 使用 NetApp Disaster Recovery 容錯回復至來源站台
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/use/


[role="lead"]
災難解決後，從災難恢復站台容錯回復到來源站台以恢復正常運作。您可以選擇用於恢復的快照。

*所需 NetApp Console 角色* 執行此任務需要 Super admin、Disaster recovery admin 或 Disaster recovery failover admin 角色。link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["了解NetApp Disaster Recovery中的使用者角色和權限"^]。link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服務的NetApp Console存取角色"^]。



[[about-failback]]
== 關於故障恢復

在容錯回復中，NetApp Disaster Recovery 會將所有變更複寫（重新同步）回原始來源工作負載，然後再反轉複寫方向。此程序在關係容錯移轉到目標之後啟動，並包含下列步驟。Kubernetes 工作負載遵循與 VMware 工作負載相同的順序；VMware 特有的細節在括號中註明。

* 對復原的站點執行合規性檢查。
* 重新整理識別為位於已恢復站台的每個 vCenter 叢集或 Kubernetes 叢集的探索資訊。
* 在目標站台上，停止受保護的工作負載（對於 VMware，關閉虛擬機器電源並取消註冊），並取下 Volume。
* 打破原始來源上的SnapMirror關係以使其可讀/寫入。
* 重新同步SnapMirror關係以逆轉複製。
* 在來源啟動受保護的工作負載（對於 VMware，啟動並註冊來源虛擬機器），並在來源裝載 Volume。




[[before-you-begin]]
== 開始之前

對於 VMware 工作負載，如果您使用以資料存放區為基礎的保護，則在容錯移轉期間，虛擬機器可能會新增至資料存放區。如果發生這種情況，請確保在啟動容錯回復之前，為這些虛擬機器提供額外的對應資訊。若要編輯資源對應，請參閱 link:manage.html#manage-replication-plans["管理複製計劃"]。



[[steps]]
== 步驟

[role="tabbed-block"]
====
.vCenter
--
.步驟
. 從災難恢復選單中，選擇 *複寫計畫*。
. 在下拉式選單中，將篩選條件設定為 *VMware* 。
+
image::site-type-toggle.png[網站類型切換的螢幕擷取畫面]

. 識別您要容錯回復的複寫計畫。選取 *Actions* 選項 image:../use/icon-horizontal-dots.png["災難恢復服務中的動作選單圖示"]，將滑鼠游標移至 *Recover* 上方，然後選取 *Failback*。
. 選擇要從中復原的資料存放區快照。選取 *立即建立快照* 以啟動新的快照，或選取 *選擇* 以從可用快照中選擇。
+

NOTE: 如果您使用防篡改 SnapLock 快照，則必須使用 *立即拍攝快照* 選項。否則作業將會失敗。

+
image:failback.png["故障回復對話方塊的螢幕擷取畫面"]

. 輸入 "Failback" 以確認操作，然後選取 *Failback*。


若要監控作業進度，請在災難復原選單中選擇「作業監控」。

--
.Kubernetes
--
. 從災難恢復選單中，選擇 *複寫計畫*。
. 在下拉式選單中，篩選 *Kubernetes* 複寫計畫。
+
image::site-type-toggle.png[網站類型切換的螢幕擷取畫面]

. 識別您要容錯回復的複寫計畫。選取 *Actions* 選項 image:../use/icon-horizontal-dots.png["災難恢復服務中的動作選單圖示"]，將滑鼠游標移至 *Recover* 上方，然後選取 *Failback*。
. 選擇要從中復原的叢集快照。選取 *Take snapshot now* 以啟動新的快照，或選取 *Use latest snapshot* 以使用最近一次成功的快照。
. 輸入 "Failback" 以確認操作，然後選取 *Failback*。


若要監控作業進度，請在災難復原選單中選擇「作業監控」。

--
