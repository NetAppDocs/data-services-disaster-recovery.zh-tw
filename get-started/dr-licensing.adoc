= 設定NetApp Disaster Recovery許可
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
NetApp Disaster Recovery 提供多種授權選項，包括免費試用、隨用隨付訂閱和自帶授權（BYOL）。在設定災難恢復之前，請確認您的授權模式，以確保服務符合您組織的需求。

*所需 NetApp Console 角色* 執行此任務需要超級管理員、災難復原管理員或災難復原應用程式管理員角色。link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["了解NetApp Disaster Recovery中的使用者角色和權限"^]。link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["了解所有服務的NetApp Console存取角色"^]。



[[licensing-options]]
== 授權選項

您可以使用以下授權選項：

* 註冊 30 天免費試用。
* 購買 Amazon Web Services (AWS) Marketplace 或 Microsoft Azure Marketplace 的即用即付 (PAYGO) 訂閱。
* 自帶授權 (BYOL)，即您從NetApp銷售代表取得的NetApp授權文件 (NLF)。您可以使用許可證序號在NetApp Console中啟動 BYOL。



NOTE: 災難恢復費用是根據來源站台的已用容量計算，前提是至少有一個虛擬機器或 Kubernetes 資源具有複寫計畫。容錯移轉資料存放區的容量不包含在容量配額中。對於 BYOL，如果資料超過允許的容量，服務中的作業將受到限制，直到您取得額外的容量授權或在 NetApp Console 中升級授權為止。

link:https://docs.netapp.com/us-en/console-licenses-subscriptions/concept-licenses-subscriptions.html["了解有關訂閱的更多信息"^]。

免費試用結束或許可證到期後，您仍然可以在服務中執行以下操作：

* 查看任何資源，例如工作負載或複製計劃。
* 刪除任何資源，例如工作負載或複製計劃。
* 執行在試用期間或許可證下建立的所有計劃操作。




[[try-it-out-using-a-30-day-free-trial]]
== 使用 30 天免費試用版嘗試

您可以免費試用災難恢復 30 天。


NOTE: 試用期間不實施任何容量限制。

試用期結束後，若要繼續，您需要購買 BYOL 授權或 PAYGO AWS 訂閱。您可以隨時獲得許可證，並且在試用期結束之前不會向您收費。

在試用期間，您可以使用全部功能。

.步驟
. 登入 https://console.netapp.com/["NetApp Console"^]。
. 從NetApp Console左側導覽中，選擇 *保護* > *災難復原*。
+
如果這是您第一次登入此服務，則會出現登入頁面。

+
image:draas-landing6-free-trial.png["災難恢復登陸頁面快照"]

. 如果您尚未為其他服務新增控制台代理，請新增一個。
+
若要新增控制台代理，請參閱 https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["了解控制台代理"^]。

. 設定代理程式後，在災難恢復活動網頁上，新增代理程式的按鈕會變成開始免費試用的按鈕。選擇 *開始免費試用*。
. 首先新增主站台和災難復原站台。
+
如需詳細資訊，請參閱link:../use/sites-add.html["新增站台"]。





[[after-the-trial-ends-subscribe-through-one-of-the-marketplaces]]
== 試用期結束後，透過其中一個市場訂閱

免費試用結束後，您可以從NetApp購買許可證，也可以透過 AWS Marketplace 或 Microsoft Azure Marketplace 訂閱。此過程提供瞭如何在其中一個市場中直接訂閱的高級概述。

.步驟
. 在災難恢復中，您會看到一則訊息，提示免費試用即將到期。在該訊息中，選取 *訂閱或購買授權*。
+
或者，從 NetApp Disaster Recovery 選單中選取 *View payment methods*。

+
image:dr-licensing-payment-methods.png["災難恢復付款方式頁面"]

. 選擇*在 AWS Marketplace 中訂閱*或*在 Azure Marketplace 中訂閱*。
. 使用 AWS Marketplace 或 Microsoft Azure Marketplace 訂閱 *災難恢復*。
. 返回災難恢復時，會顯示一則訊息，表示您已訂閱。
+
您可以在NetApp Console訂閱頁面查看訂閱詳細資訊。link:https://docs.netapp.com/us-en/console-licenses-subscriptions/task-homepage.html["詳細了解如何使用NetApp Console管理訂閱"^]。





[[after-the-trial-ends-purchase-a-byol-license-through-netapp]]
== 試用結束後，透過NetApp購買 BYOL 許可證

試用結束後，您可以透過NetApp銷售代表購買授權。

如果您自帶許可證 (BYOL)，設定包括購買許可證、取得NetApp許可證文件 (NLF) 以及將許可證新增至NetApp Console。



[[add-the-license-to-the-netapp-console]]
=== 將授權新增至 NetApp Console

向 NetApp 銷售代表購買災難恢復授權後，您可以在主控台中管理該授權。

https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["了解如何使用NetApp Console新增許可證"^]。



[[update-your-license-when-it-expires]]
== 許可證到期時更新

如果您的授權期限即將到期，或者您的授權容量即將達到上限，您將在災難恢復使用者介面中收到通知。您可以在災難恢復授權到期前進行更新，以確保服務使用不中斷。


TIP: 此訊息也會出現在NetApp Console和 https://docs.netapp.com/us-en/console-setup-admin/task-monitor-cm-operations.html#monitoring-operations-status-using-the-notification-center["通知"]。

https://docs.netapp.com/us-en/console-licenses-subscriptions/task-manage-data-services-licenses.html["了解如何使用NetApp Console更新許可證"^]。



[[end-the-free-trial]]
== 結束免費試用

您可以隨時停止免費試用，也可以等到試用期結束。

.步驟
. 在災難恢復中，選擇 *免費試用 - 檢視詳細資料*。
. 在下拉詳細資料中，選擇*結束免費試用*。
+
image:draas-trial-end3.png["結束免費試用頁面"]

. 如果您想刪除所有數據，請勾選*結束免費試用後立即刪除數據*。
+
此操作將刪除所有排程、複寫計畫、資源群組、vCenters、Kubernetes 叢集和站台。稽核資料、作業記錄和工作歷程記錄將保留至產品生命週期結束。

+

NOTE: 如果您結束免費試用，未要求刪除資料，且未購買授權或訂閱，則災難恢復將在免費試用結束後 60 天刪除您的所有資料。

. 在文字方塊中輸入「結束試用」。
. 選擇*結束*。
