= 存取NetApp Disaster Recovery
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/get-started/


[role="lead"]
若要登入 NetApp Disaster Recovery，請使用您的 NetApp 支援網站憑證，或使用您的電子郵件地址和密碼註冊 NetApp 雲端登入 https://docs.netapp.com/us-en/cloud-manager-setup-admin/task-logging-in.html["了解有關登入的更多信息"^]。



[[user-roles]]
== 使用者角色

在災難恢復中，特定任務需要特定的使用者角色。請確保您已為使用者分配正確的角色。

如需詳細資訊，請參閱： * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-disaster-rec-roles.html["NetApp Disaster Recovery 中的使用者角色和權限"] * link:https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["NetApp Console 所有服務的存取角色"^]



[[log-into-disaster-recovery]]
== 登入災難恢復

. 開啟網頁瀏覽器。前往 https://console.netapp.com/["NetApp Console"^]。
. 登入NetApp Console。
. 從NetApp Console左側導覽中，選擇 *保護* > *災難復原*。
+
如果這是您第一次登入此服務，則會出現登入頁面，您可以註冊免費試用。

+
image:draas-landing6-free-trial.png["災難恢復登陸頁面快照"]

+
否則，將顯示災難恢復儀表板。

+
** 如果您尚未新增 NetApp Console 代理程式，請新增一個。如需詳細資訊，請參閱 https://docs.netapp.com/us-en/console-setup-admin/concept-connectors.html["了解控制台代理"^]。
** 如果您是擁有現有代理程式的主控台使用者，當您選擇 *災難恢復* 時，將顯示有關註冊的訊息。
** 如果您已經在使用該服務，當您選擇「災難復原」時，就會出現儀表板。
+
image:dr-dashboard.png["災難恢復儀表板"]
